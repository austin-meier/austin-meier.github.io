clojure.pdf

A from-scratch, zero-dependency PDF generation library built on the PDF 2.0 spec, with a data-first API where every document is just a plain map. Handles TrueType font embedding and subsetting, images, a flexbox-style layout engine with pagination, SVG vector graphics, and a parser that round-trips existing PDFs back into editable form, all sharing a portable binary codec that runs on both the JVM and JavaScript.
